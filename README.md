# Pharmacy Management System

## DBMS Capstone Project

The Pharmacy Management System is a database application designed
to manage pharmacy operations using a centralized relational database.

## Features

- Patient Management
- Doctor Management
- Hospital Management
- Pharmacy Management
- Employee Management
- Medicine Inventory
- Supplier Management
- Billing Management
- SQL Queries
- Database Normalization

## Technologies Used

- Oracle Database
- SQL
- ER Modeling
- Database Normalization

## Database Concepts

- Primary Keys
- Foreign Keys
- Constraints
- Joins
- Aggregate Functions
- Subqueries
- 1NF
- 2NF
- 3NF
